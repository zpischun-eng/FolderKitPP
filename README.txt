FolderKit++ v51.3 안내
======================

FolderKit v50을 이어받은 새 이름의 프로그램입니다.
기존 네 모드(동기화 / 파일명 변경 / 이미지 편집 / 중복 찾기)는 그대로이고,
다섯 번째 모드인 "유틸리티"(미니앱 모음)가 새로 들어갔습니다.

유틸리티 모드 카테고리: 수학(공학용 계산기·함수 그래프) /
정보컴퓨터(카르노맵·CPU 스케줄링) / 학교(오늘의 급식·학교 일정, 나이스 연동, 코돈시뮬, 좌석표, 시간표,
행운의 번호, 응원의 메시지)

폴더 구조
---------
FolderKitPP.py         : 실행 진입점 (이 파일을 실행)
FolderKitPP.spec       : PyInstaller 빌드 설정
requirements.txt       : 필요 패키지 목록
tests_headless.py      : 헤드리스 자동 검증 (1080개 항목)
assets/                : 아이콘
docs/                  : 계획서, 개발 이력, 미니앱 추가 가이드
src/                   : 실제 소스 코드
src/utils/             : 유틸리티 미니앱들 (레지스트리 + 각 미니앱)

실행 방법
---------
1. pip install -r requirements.txt
2. python FolderKitPP.py

★ 더 쉬운 실행 방법: run.bat ★
PySide6를 설치한 파이썬과, 실제로 FolderKitPP.py를 실행하는 "python" 명령이
서로 다른 파이썬을 가리켜서 "ModuleNotFoundError: No module named 'PySide6'"
오류가 나는 경우가 있습니다(파이썬을 여러 개 설치해 둔 PC에서 흔함).
이 문제를 피하려면, 이 폴더의 run.bat을 더블클릭해서 실행하세요 — PySide6가
실제로 설치되어 있는 파이썬(C:\Python312\python.exe)을 직접 지정해서 실행
합니다. 만약 파이썬 설치 경로가 다르다면 run.bat을 메모장으로 열어 그
경로만 수정하면 됩니다.

exe로 만들기 (Windows에서)
---------------------------
FolderKitPP.py가 있는 폴더에서:
    pyinstaller FolderKitPP.spec

또는 직접 옵션을 주려면:
    pyinstaller -w -F --icon=assets/FolderKit_icon.ico --add-data "assets;assets" --name FolderKitPP FolderKitPP.py

(--add-data의 세미콜론은 Windows 기준. macOS/Linux에서는 콜론(:) 사용)
(만약 'pathlib' 관련 오류가 나오면: pip uninstall pathlib 실행 후 다시 시도)

★ 빌드 전 꼭 확인하세요 ★
pyinstaller를 실행하는 것과 같은 파이썬 환경에서 아래 명령으로 선택 라이브러리들이
실제로 설치되어 있는지 확인한 뒤 빌드하세요. **exe를 실행하는 컴퓨터가 아니라
exe를 만드는(빌드하는) 이 컴퓨터에 설치되어 있어야 합니다** — 여기 없으면
빌드 자체가 조용히 그 라이브러리를 건너뛰어서, 나중에 어떤 컴퓨터에서 실행해도
그 기능(엑셀 출력, 휴지통 삭제, HEIC 열기 등)이 빠진 채로 나옵니다. "라이브러리가
없는 컴퓨터에서만 엑셀 다운로드가 안 된다"는 제보를 실제로 받았는데, 원인은 실행하는
컴퓨터가 아니라 **빌드했던 컴퓨터에 애초에 openpyxl이 없었던 것**이었다 — exe 안에
제대로 들어있으면 실행하는 컴퓨터에는 아무것도 따로 설치할 필요가 없다(그게 이런
방식으로 배포하는 이유다):
    python -m pip show send2trash
    python -m pip show openpyxl
    python -m pip show xxhash
    python -m pip show pillow_heif
위 네 개 중 하나라도 "WARNING: Package(s) not found"가 나오면, 그 라이브러리가
필요한 기능(각각 휴지통 삭제 / 엑셀 출력·입출력 / 중복 찾기 빠른 스캔 / HEIC 이미지)
없이 exe가 만들어집니다. 이 프로젝트의 FolderKitPP.spec은 이 네 가지를 모두
hiddenimports에 명시적으로 넣어 두었으니, **설치만 되어 있으면** 확실히 exe에
포함됩니다(설치가 안 되어 있는 항목은 조용히 건너뛰고 나머지는 정상 빌드됩니다).
모두 선택 사항이라 없어도 프로그램 자체는 정상 동작하지만, 해당 기능만 "설치 안내"
메시지로 대체됩니다. 급식/일정의 인쇄 기능은 PySide6에 이미 포함된
QtPrintSupport를 쓰므로 추가로 설치할 것이 없습니다.

미니앱 요약 (자세한 내용은 CHANGELOG.md)
-----------------------------------------
[수학]
- 공학용 계산기 — 수식 전체를 유지한 채 한 번에 계산하고, 계산한 수식을
  기록에서 다시 불러와 고칠 수 있습니다. 처음 열면 모든 연산자를 담은
  샘플 수식이 기록에 미리 들어있고, 각 줄에 원클릭 복사 버튼이 있습니다.
- 함수 그래프 — f(x)를 입력하면 즉시 그래프를 그립니다(최대 6개 동시
  비교, 확대/축소·이동, 점근선 자동 처리). 축은 진하게 강조되고 원점·
  화살표가 표시되며, x/y절편을 점+좌표로 보여줍니다(점근선은 절편으로
  착각하지 않음). 이미지로 저장 가능. x축을 드래그해 값을 추적하고
  고정한 뒤, 곡선 위 점을 클릭해 접선·수직선을 그릴 수 있습니다.
- 극좌표 그래프 — r=f(θ) 형태(심장형·장미선·나선 등)를 등각(1:1 비율)
  으로 그립니다. 예시 곡선 6종 제공.

[정보컴퓨터]
- 카르노맵 — 칸을 클릭하면 그 즉시 최소화된 논리식을 보여줍니다. 2~6변수
  지원(5·6변수는 단일 테이블: 4×8, 8×8). f(A,B,...)= 입력창으로 minterm을
  한 번에 넣을 수 있고 표와 양방향 동기화됩니다. 엑셀 출력 지원.
- CPU 스케줄링 — 프로세스를 여러 개 등록하고 FCFS/SJF/SRTF/우선순위(비선점·
  선점)/라운드 로빈/HRN 중 기법을 고르면 간트차트로 실행 순서를 보여줍니다.
  기법별 예제 6종, 단계 재생(대기 큐 확인), PNG/엑셀 저장 지원.

[학교] (나이스 개방포털 연동 — 인증키·학교 코드를 세 도구가 공유)
- 오늘의 급식 — 날짜별·주간·월별 중식 정보. 드래그로 텍스트 선택해
  복사, 가로 방향(A4)에 페이지 폭 꽉 차게 인쇄.
- 학교 일정 — 달력에 직접 입력하는 연간계획(주된 자료) + 나이스 학사일정
  (참고용, 옅은 칩으로 구분)을 함께 보여줍니다. 일정 추가·수정·삭제는
  인증키 없이도 가능합니다. 엑셀 일괄 입력/출력, 인쇄 지원.
- 나이스 글자수 계산기 — 학생부 서술형 항목의 바이트수를 세고(한글
  3바이트/영문 1바이트/엔터 2바이트), 기재 유의 표현(공인어학시험·
  교외대회·논문·해외활동·특정 대학명·학교명 노출 등 9개 항목)을
  키워드+정규식으로 점검합니다. 확정 판정이 아닌 보조 참고용입니다.
- 대진표 작성기 — 체육 수업용 조 편성·토너먼트(부전승 자동 처리)·
  리그(조별리그) 일정을 무작위로 만듭니다.
- 코돈표 계산기 — DNA·mRNA 서열을 표준 유전암호표로 아미노산 서열로
  번역하고, 아미노산->코돈 역조회와 전체 코돈표를 제공합니다.
- 코돈시뮬(CodonSim) — 기출 문제(2019 수능 생명과학Ⅰ 21번)를 w에서
  시작해 x->y->z로 이어지는 변이를 직접 만들어 가며 풉니다. 서열을
  클릭해 위치를 고르고 삽입/삭제/치환을 적용하면 오른쪽 조건 판정판이
  실시간으로 채점하고, <보기> ㄱ/ㄴ/ㄷ에 O/X로 답하면 현재 만든 서열
  기준으로 채점합니다. 힌트 2단계->정답 보기->자동 채우기 순서로 막히면
  도와주며, "직접 입력"을 고르면 원하는 주형 가닥으로 자유롭게 실험할
  수 있습니다(이 경우 조건·<보기> 없이 탐색만 가능).
