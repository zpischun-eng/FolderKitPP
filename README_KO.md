# FolderKit++ v51.3

FolderKit v50을 이어받아, **폴더·이미지 도구**에 **수업/업무용 미니 유틸리티**를
더한 프로그램입니다.

## 📋 다섯 가지 모드

| 모드 | 색상 | 기능 |
|------|------|------|
| **동기화** | 파랑 | 좌·우 두 폴더를 비교해서 파일을 맞춥니다 |
| **파일명 변경** | 주황 | 폴더 내 파일·폴더 이름을 일괄 바꿉니다 |
| **이미지 편집** | 보라 | 이미지를 크롭하고 밝기 곡선을 조정합니다 |
| **파일 찾기** | 틸 | 상단 세그먼트로 "중복 파일 찾기"(내용이 같은 파일을 찾아 정리)와 "확장자로 찾기"(원하는 확장자 파일만 모아 보기)를 오갑니다 |
| **유틸리티** ✨ | 자홍 | 계산기 등 수업·업무에 자주 쓰는 작은 도구 모음(계산·논리·그래프·학교) |

좌측 세로 아이콘 바에서 모드를 전환합니다. 폴더 트리·콘솔 로그·진행바·상태바는
모든 모드가 공유합니다.

## ✨ v01 새 기능: 유틸리티 모드

### 화면 구성

```
[아이콘바] │ [검색창 · 도구 모음 버튼 ······ 도구: 공학용 계산기]
          ├──────────────┬──────────────────────────────────┐
          │ ⌂ 전체 도구   │                                  │
          │ ─ 계산 ─      │      선택한 도구의 화면           │
          │  🧮 공학용… │      (아무것도 안 고르면 카드 그리드) │
          └──────────────┴──────────────────────────────────┘
```

- **홈 카드** — 어떤 도구가 있는지 한눈에 보고 카드를 눌러 엽니다.
- **좌측 목록** — 익숙해지면 한 번의 클릭으로 도구를 바꿉니다.
- **검색** — 도구 이름·설명의 일부를 입력하면 목록과 카드가 함께 걸러집니다.
- **최근 사용** — 도구가 2개 이상 쌓이면 목록 맨 위에 생깁니다.
- 마지막에 쓰던 도구는 다음에 들어올 때 그대로 열립니다.

### 🧮 공학용 계산기

윈도우 기본 계산기는 연산자를 누르는 순간 앞부분이 계산되어 사라져서
**내가 넣은 수식 전체를 볼 수 없습니다.** 이 계산기는 그 반대로 동작합니다.

| | |
|---|---|
| **수식 유지** | `=`를 누르기 전까지 아무것도 먼저 계산하지 않습니다 |
| **입력 중 미리보기** | 수식은 그대로 두고 현재 값만 회색으로 보여줍니다 |
| **계산 후 편집** | 결과가 나와도 수식이 남아 있어 숫자만 고쳐 다시 계산 |
| **기록 재활용** | 오른쪽 기록을 클릭 → 그 수식이 입력창으로 돌아옵니다 |

**단축키**

| 키 | 동작 |
|---|---|
| `Enter` | 수식 전체 계산 |
| `↑` / `↓` | 이전에 계산한 수식 불러오기 |
| `Esc` | 수식 지우기 |

**기록 사용법**

- 한 번 클릭 → 수식을 입력창으로 불러오기(편집용)
- 두 번 클릭 → 불러온 뒤 바로 계산
- 각 줄의 ⧉ 버튼 → 그 수식만 바로 복사(오른쪽 클릭 메뉴에서 수식/결과를 따로 골라 복사할 수도 있습니다)
- 오른쪽 클릭 → 수식 복사 / 결과 복사 / 이 항목 삭제

처음 열면 모든 연산자를 담은 샘플 수식이 기록에 1건 미리 들어있습니다. 프로그램을
껐다 켜도 기록이 남습니다(최대 60건).

**입력 요령**

- 화면에는 `×` `÷` `√` `π`로 보이지만, 키보드로 `*` `/`를 그대로 쳐도 됩니다.
- `4`를 누른 뒤 `√`를 누르면 곱셈 기호가 자동으로 들어갑니다 → `4×√(`
- 수식 일부를 드래그해 선택하고 `√`를 누르면 그 부분을 감쌉니다 → `√(3+4)`
- `mod`는 나머지입니다(`7 % 3 = 1`). `!`는 계승(`5! = 120`), `^`는 거듭제곱입니다.
- `log(8, 2)`처럼 밑을 직접 적을 수 있고, `ans`는 바로 앞 계산 결과입니다.
- 삼각함수의 각도 단위는 왼쪽 위 **DEG / RAD** 버튼으로 바꿉니다.

### 🗺️ 카르노맵 (논리식 최적화)

칸을 클릭할 때마다(0 ↔ 1) **그 즉시** 최소화된 논리식을 다시 계산해 보여줍니다.
**2~6변수**를 모두 지원합니다.

| | |
|---|---|
| **즉시 반응** | 칸을 누르는 순간 오른쪽 논리식이 바로 갱신됩니다 |
| **5·6변수** | 단일 테이블(5변수=4×8, 6변수=8×8)로 표현되며, 그레이 코드가 순환 구조라 표 끝과 시작도 1비트만 다릅니다 |
| **교과서 표기** | 부정 리터럴에 윗줄을 그어(A̅) 표시합니다 |
| **그레이 코드 헤더** | 행/열 머리글이 그레이 코드 순서로 표시되어, 옆 칸이 항상 1비트만 다르다는 카르노맵의 성질을 그대로 보여줍니다 |

- 각 칸에 마우스를 올리면 그 칸의 민텀 번호와 비트값이 툴팁으로 뜹니다.
- 변수 이름은 쉼표로 구분해 바꿀 수 있습니다(기본 A,B,C,D,E,F). 표 좌상단에 행/열 변수가 줄바꿈으로 나뉘어 표시됩니다.
- **f(A,B,C,...) =** 입력창에 `1,2,4,5,6,10`처럼 민텀 번호를 쉼표로 구분해 한 번에 입력할 수 있습니다. 표를 클릭해도 이 입력창이 그대로 동기화됩니다(양방향).
- **논리식 복사** 버튼을 누르면 `A'B' + AC` 형태(아포스트로피)로 복사됩니다.
- **엑셀 출력** 버튼으로 표 상태와 최소화된 논리식을 `.xlsx` 파일로 저장할 수 있습니다(`openpyxl` 필요 — 선택 사항, 설치돼 있지 않으면 안내만 뜨고 프로그램은 정상 동작합니다).
- 전체 0 / 전체 1 버튼, 항 개수·리터럴 개수 통계, Σm(...) 민텀 목록을 함께 보여줍니다.

### 🖥️ CPU 스케줄링 (간트차트)

프로세스(이름·도착 시간·실행 시간·우선순위)를 표에 여러 개 등록하고 기법을
고르면, 그 기법에 따라 CPU가 프로세스를 어떤 순서로 실행하는지 간트차트로
보여줍니다.

| | |
|---|---|
| **지원 기법 7종** | FCFS, SJF(비선점), SRTF(선점), 우선순위(비선점·선점), 라운드 로빈(시간 할당량 조절), HRN |
| **예제 6종** | 콤보에서 기법별 대표 예제를 고르면 표·기법·할당량이 한 번에 채워집니다 |
| **단계 재생** | ◀/▶/재생 버튼으로 시각을 한 단위씩 옮기며 그 순간의 대기 큐를 확인할 수 있습니다 |
| **결과 패널** | 프로세스별 완료·반환·대기·응답 시간과 평균값, CPU 이용률, 처리량을 보여줍니다 |

- 간트차트는 PNG로, 결과표는 Excel로 저장할 수 있습니다(Excel은 `openpyxl` 필요 — 선택 사항).
- 칸 너비 슬라이더로 간트차트를 확대/축소할 수 있습니다.
- 입력한 프로세스 목록과 기법·할당량은 자동으로 저장되어 다음에 열었을 때도 유지됩니다.

### 🔢 스도쿠 — v46, v46.1에서 재시도(라이프) 시스템 추가

9×9 스도쿠를 풀 수 있습니다. 난이도(쉬움/보통/어려움)는 빈 칸 개수로
나뉘고, 문제를 낼 때마다 답이 정확히 하나만 나오도록(유일해) 검증해서
냅니다.

| | |
|---|---|
| **입력** | 마우스로 칸을 고른 뒤 숫자 패드(정사각형에 가까운 큰 버튼) 또는 키보드(1~9) — 방향키로 칸 이동, Backspace/Delete로 지우기 |
| **메모** | "메모" 버튼을 켠 채 숫자를 누르면 그 칸에 후보 숫자가 작게 쌓입니다(확정 숫자를 넣으면 자동으로 지워짐) |
| **강조 표시** | 선택한 칸과 같은 행·열·3×3박스, 같은 숫자가 든 다른 칸을 옅게 강조합니다 |
| **재시도(라이프)** | 카드 제목줄의 초록 등 3개 — 오답을 넣거나 힌트를 쓸 때마다 하나씩 꺼집니다 |
| **힌트** | 빈 칸 하나를 정답으로 채워 줍니다(재시도 하나를 씁니다) |

- 고정 숫자(문제)는 진한 검정, 직접 입력한 숫자는 분홍색으로 구분됩니다.
- **오답을 넣으면 그 숫자는 보드에 반영되지 않고** 바로 오답 메시지가 뜨며 재시도가 하나 줄어듭니다.
- 재시도를 세 번 다 쓰면 창이 뜨고, 같은 문제를 처음부터 다시 풀거나("재도전") 새 퍼즐을 받을 수 있습니다.
- 남은 빈 칸이 전부 논리적으로 값이 하나씩만 정해진 상태가 되면, 자동으로 완성할지 묻는 창이 뜹니다(재시도를 쓰지 않습니다).
- 숫자가 채워진 칸을 선택하면 그 숫자와 같은 숫자가 든 칸들, 그리고 선택한 칸의 행·열·3×3박스가 함께 강조됩니다.
- 숫자 하나가 9칸에 모두 채워지면 그 숫자 버튼은 자동으로 꺼집니다(키보드 입력도 함께 막힙니다).
- 모든 칸을 정답으로 채우면 완성 메시지가 뜹니다.
- 라이프를 다 써서 "새 퍼즐"을 고르면 실패한 퍼즐이 **보관함**에 저장됩니다. "보관함" 버튼으로 목록을 열어 다시 불러올 수 있고(채운 칸은 그대로, 라이프는 3회로 리셋), 완성하면 보관함에서 자동으로 지워집니다.

### 📈 함수 그래프

f(x) 형태의 식을 입력하면 즉시 곡선을 그립니다. **최대 6개**까지 겹쳐 비교할 수 있습니다.

| | |
|---|---|
| **확대/축소** | 마우스 휠 — 커서가 가리키는 지점을 고정한 채 확대·축소됩니다 |
| **이동** | 마우스 드래그 |
| **좌표 확인** | 커서를 올리면 (x, y)가 십자선과 함께 표시됩니다 |
| **Y축 자동 맞춤** | 기본 켜짐 — 보이는 X 구간에 맞춰 Y축이 스스로 조정됩니다 |

- 함수마다 색이 다르고, 색 스와치를 클릭하면 다른 색으로 바뀝니다. 체크박스로 표시/숨김을 전환합니다.
- `tan(x)`처럼 점근선이 있는 함수도 세로 직선으로 잘못 이어지지 않고 정확히 끊어져 그려집니다.
- `sqrt(x)`처럼 일부 구간에서 정의되지 않는 함수는 그 구간만 자연스럽게 비어 보입니다.
- 식이 잘못되면 입력창 옆과 그래프 위에 바로 이유가 표시됩니다.
- 더블클릭 또는 **보기 초기화** 버튼으로 기본 화면(-10~10)으로 돌아갑니다.
- 함수 내용·좌표축 범위·각도 모드는 프로그램을 껐다 켜도 유지됩니다.
- **원점(O)**과 **x/y축 화살표**가 표시됩니다(축은 진한 남색으로 강조).
- **절편 표시** 체크박스로 각 함수의 x절편·y절편을 점+좌표로 켜고 끌 수 있습니다
  (`tan(x)`의 점근선은 절편으로 착각하지 않습니다).
- **이미지로 저장** 버튼으로 지금 보이는 그래프를 PNG로 저장합니다.
- **x축을 클릭하고 드래그**하면 그 지점의 값을 보라색 선으로 추적합니다(곡선과 만나는 점,
  y축까지 이어지는 선, y축 위 값 표시). 손을 놓으면 회색 점선으로 고정되고, x축 위 숫자를
  클릭하면 정확한 값을 직접 입력할 수 있습니다.
- 곡선 위의 점(●)을 클릭하면 그 점이 화면에 계속 남습니다. 그 점을 **마우스
  오른쪽 클릭**하면 뜨는 메뉴에서 **접선**·**법선**(접선과 수직인 직선)을 그리거나
  지울 수 있고, 여러 점에 동시에 그릴 수 있습니다(새 점을 찍어도 이전 점·선은
  사라지지 않음). 선이 그려진 점은 빨간 원으로 표시됩니다.

### 🌀 극좌표 그래프

r=f(θ) 형태의 극좌표 함수(심장형·장미선·나선 등)를 그립니다. 식에는 θ를 `theta`로 씁니다.

| | |
|---|---|
| **등각(1:1 비율)** | 원이 타원처럼 보이지 않도록 가로세로 배율을 항상 같게 맞춥니다 |
| **예시 곡선** | 심장형·장미선(3잎/4잎)·원·나선·연주형 근사 6종을 한 번에 불러올 수 있습니다 |
| **θ 범위** | 시작~끝을 직접 조절할 수 있습니다(나선처럼 여러 바퀴 도는 곡선에 유용) |

확대/축소·이동·이미지 저장·설정 저장은 함수 그래프와 같은 방식입니다.

### 🍚 오늘의 급식

나이스 개방 포털에서 날짜별·주간·월별 중식 정보를 받아옵니다. **인터넷 연결이 필요한 첫 도구**입니다.

| | |
|---|---|
| **기본값** | 교육청코드·학교코드가 선린인터넷고등학교로 이미 설정되어 있습니다 |
| **일별/주간/월별** | 세 버튼으로 전환 — 주간·월별 모두 **월~금**만 표로 보여줍니다(월별은 그 달의 주 수만큼 여러 줄) |
| **날짜 이동** | ◀ ▶ 버튼(주간은 한 주씩, 월별은 한 달씩) 또는 달력, **오늘** 버튼으로 빠르게 이동 |
| **화면 스크롤** | 월별처럼 내용이 길어지면 자동으로 세로 스크롤됩니다 |
| **드래그 복사** | 마우스로 드래그하면 여러 줄을 한 번에 선택해 복사할 수 있습니다 |

4. **선린인터넷고가 아닌 다른 학교**라면, 학교명 칸에 학교 이름을 입력하고 **검색** 버튼을

### 🪑 좌석표

학급별로 무작위 좌석표를 만듭니다. 명단이 없어도 인원 수만 입력하면 1~N번으로
바로 배치를 만들어 볼 수 있고, "입력 양식 다운로드"(기본 저장 위치: 바탕화면)로 빈 엑셀을 받아 채운 뒤
올리면 실제 이름 기반으로 자동 전환됩니다(대진표 작성기와 같은 형식 —
학년·반·번호·이름·성별에 더해, 좌석표만 마지막 칸에 **역할**을 자유롭게 적을
수 있습니다: 반장·부반장·출석부·칠판·실습실 등. 역할 칸은 비워 둬도 되고,
대진표 작성기 쪽 양식·업로드에는 영향이 없습니다). 반을 고르면 설정 카드에서
정한 줄(분단) 수에 맞춰 곧바로
배치되고, 인원이 안 나누어떨어지면 빈 자리가 생깁니다 — **자리를 클릭한 뒤 옮기고
싶은 칸을 이어서 클릭하면 두 자리가 서로 바뀌어**, 빈 자리 위치도 원하는 곳으로
옮길 수 있습니다. 교탁은 화면 아래, 뒷줄은 위로 표시됩니다(칠판을 마주 보는 모습
그대로). "랜덤 배정"으로 자리만 새로 배치할 수 있고, "저장 폴더 선택"으로 폴더를
정해 두면 반마다 마지막 배치가 "좌석표_학년반.json" 파일로 계속 저장되어 다음에
그 반을 다시 열면 이어서 보입니다(안 정하면 앱을 닫을 때 사라집니다). "명단
지우기"는 지금 올려 둔 학급 명단을 전부 비웁니다. 인쇄하면 A4 가로로 자동
맞춰지고, "인쇄" 버튼에서 1쪽(가로 꽉 채움)/2쪽(세로 위아래)/4쪽(가로 2x2) 중
고를 수 있습니다. 배치표가 가로로 넓은 편이라 설정 카드 3개는 화면 아래에
나란히 두고, 배치표 자체가 화면 대부분을 씁니다.

"역할 보기" 체크박스(기본은 꺼짐)를 켜면 명단에 적어 둔 역할이 각 자리
이름 아래에 작게 함께 표시됩니다 — 역할이 없는 학생은 그 자리만 비어
있습니다. 꺼져 있을 때는 화면이 지금까지와 완전히 같습니다.

자리를 **오른쪽 클릭**하면 공석·여학생·남학생·지정석 중 하나로 지정할 수
있습니다(새 배치는 전부 남학생/옅은 파랑으로 시작하고, 여학생은 옅은 빨강, 공석은
빗금 무늬입니다). 이후 "랜덤 배정"이나 명단 업로드로 다시 배치하면 남학생은
남학생 칸에, 여학생은 여학생 칸에만 무작위로 앉고, 공석 칸에는 아무도 앉지
않습니다(자리별 지정은 다시 섞어도 유지). **지정석**으로 특정 학생(번호)을 고르면
그 학생이 그 자리에 바로 옮겨지고, 이후 계속 그 자리에 고정됩니다("지정석 해제"로
풀 수 있음) — 나머지 자리만 무작위로 채워집니다. 학생이 있는 자리를 공석으로
지정해도 다른 빈 자리가 있으면 그 학생은 그리로 바로 옮겨져 사라지지 않습니다.

목표값까지 한 자리씩 "촤라락" 연속으로 넘어갑니다. ⛶ 버튼(또는 Esc)으로
보드만 전체화면으로 띄울 수 있고, 타이머 모드에서는 스페이스바로 시작/일시정지를
오갈 수 있습니다.

### 🗓️ 시간표

나이스 공식 API(hisTimetable)로 학급 시간표를 봅니다. 표 위 한 줄에서 학급/교사
시간표를 라디오 버튼으로 고르고, 학급 모드에서는 학년·반을 콤보박스로 고릅니다.
◀ 이번 주 ▶ 로 주를 옮기면 그 주의 시간표가 표로 나오고, 과목 아래에는 담당교사
이름이 표시됩니다(매핑돼 있으면). 인증키·교육청코드·학교코드는 오늘의 급식·학교
일정과 완전히 같은 값을 공유합니다(급식에서 Ctrl+Shift+F10으로 채운 인증키가
여기서도 그대로 보입니다).

"교사 시간표"를 고르면 학년·반은 숨고 교사 선택 콤보만 남습니다 — 여기 표시되는
시간표는 그 교사가 **담당하는 모든 반**을 가로질러 모은 것이라(한 반의 시간표만
보는 게 아니라), 과목 아래에는 담당 반이 표시됩니다. "전체 과목 다운로드"를 누르면
1~3학년 x 1~10반 전체를 조회해(교사 한 명이 여러 반을 가르치므로 한 학급만 봐서는
부족합니다) 나온 과목을 곧바로 엑셀로 저장합니다. 담당교사 이름을 채운 뒤 "교사
목록 업로드"로 다시 올리면 매핑에 반영됩니다("전체 과목 다운로드"를 한 번도 안
돌려도 지금 조회된 학급에 매핑된 교사가 있으면 바로 나옵니다). 서버 오류가 나도
마지막으로 불러온 시간표를 그대로 보여주고 캐시된 결과라고 안내합니다.

"인쇄" 버튼을 누르면 한 장에 시간표를 몇 번 담을지 고릅니다 — 1쪽(가로로 꽉
채워 1번), 2쪽(세로 방향으로 위아래에 한 번씩, 잘라서 2장으로), 4쪽(가로 방향
2행 2열로 4번, 잘라서 4장으로).

### 🗂️ 사진첩 — 행사별 자동 분류([v48], 이미지 편집 모드)

사진들이 아래 썸네일 줄에 깔리고, 편집 기능은 폴더에서와 똑같이 씁니다.

- 자동 분류: 촬영 시각과 배경(색·밝기 배치)으로 묶습니다. 새로 생긴 사진만

  (Ctrl·Shift로 여러 장). 행사 더블클릭(F2) → 이름 바꾸기. 행사 여러 개를
  골라 오른쪽 클릭 → 합치기.
- "다시 분류": 직접 손댄 행사는 그대로 두고 나머지만 다시 묶습니다.
- 원본 파일은 옮기지 않습니다. 분류 기록은 `보관함/.folderkit/photo_album.db`.

**[v49.1] 사진 보기·목록 이동**
- 원본 사진 영역에서 **Ctrl+마우스 휠**로 확대/축소(커서 위치 기준). 확대 중에는 휠로
  위아래, Shift+휠로 좌우, 가운데 버튼을 누른 채 끌어서 이동. 가운데 버튼 두 번 클릭은
  화면에 맞춤.
- 사진첩 목록은 위/아래 화살표로 옮겨도 클릭과 똑같이 사진이 바뀝니다.
- 이름 붙인 행사에도 날짜가 함께 보입니다(예: 학교 축제 · 2026/11/08).

**[v49] 장소·인물**
- 장소: 사진의 GPS로 시·도 → 시·군·구(해외는 나라 → 도시)별로 묶습니다.
  인터넷이 필요 없습니다. GPS가 없는 사진은 "위치 정보 없음"에 모입니다.
- 인물(선택 설치): `pip install opencv-python` 후, 따로 받은
  `FolderKitPP_FaceModels.zip`의 `models` 폴더를 프로그램 폴더에 넣으면 사진첩에
  "인물" 목록이 생깁니다. 인물을 더블클릭해 이름을 붙이고, 썸네일 오른쪽 클릭으로
  "다른 인물로 옮기기 / 새 인물 / 이 사람이 아님"을 고칩니다. 얼굴 정보는 보관함
  안에만 저장됩니다.

### 📱 갤럭시폰 사진 옮기기(adb 전용, 처음엔 숨김)

일반적이지 않은 도구라 평소엔 도구 목록·홈 화면 어디에도 안 보입니다.
**Ctrl+Shift+F9**를 한 번 누르면 Util 모드로 전환되면서 바로 열리고, 그
순간부터는 다른 도구와 똑같이 도구 목록·홈 화면·최근 사용에 계속 나타납니다
(단축키는 "처음 한 번 꺼내는" 용도일 뿐이고, 그 뒤로는 평소처럼 클릭해서
쓰면 됩니다 — 프로그램을 다시 시작하면 다시 숨김 상태로 돌아갑니다).

**[v47] 새 사진 가져오기(증분 동기화)** — 화면 오른쪽 위 카드에서 "보관함 지정"으로
사진을 모아 둘 폴더를 한 번 정해 두면, "새 사진 가져오기"를 누를 때마다 **아직
가져오지 않은 사진만** 골라 `보관함/2026/2026-11/` 같은 연/월 폴더로 내려받습니다.
무엇을 가져왔는지는 보관함 안의 `.folderkit/phone_sync.db`에 기록되므로, 보관함을
USB나 다른 컴퓨터로 통째로 옮겨도 이어서 쓸 수 있습니다. 처음 가져올 때는 "전부
가져오기"와 "지금부터만"(지금 있는 사진은 이미 옮긴 것으로 표시) 중에서 고릅니다.
도중에 취소하거나 연결이 끊겨도 받은 데까지는 기록되어 다음에 이어받습니다.
왼쪽 목록에서 날짜를 체크하면 버튼이 "선택만 가져오기"로 바뀌고 체크한 날짜의
새 사진만 가져옵니다([v47.1]). 목록 위 "전체 선택"으로 한 번에 체크·해제할 수
있고, 날짜에는 연도가 함께 표시됩니다.

**[v47] 무선 연결** — "무선 연결" 버튼으로 케이블 없이 연결할 수 있습니다(Android 11
이상, 폰과 컴퓨터가 같은 와이파이). 폰의 개발자 옵션에서 "무선 디버깅"을 켜고, 처음
한 번만 페어링 코드를 입력한 뒤 화면에 보이는 "IP 주소 및 포트"로 연결합니다. 기기
간 통신을 막아 둔 와이파이(학교·공공망 등)에서는 연결되지 않을 수 있으니, 그럴 땐
케이블을 쓰세요. 케이블과 무선이 함께 연결돼 있으면 더 빠른 케이블을 씁니다.

**날짜(행사)별 다운로드** — adb로 연결한 폰의 DCIM/Camera를 촬영일자 기준으로 훑어, 연속된 날짜는 하나의
"행사" 구간으로 묶어 보여줍니다. 원하는 행사만 체크해 "다운로드"를 누르면 저장
폴더를 고르고 그대로 내려받습니다. 완료 후 "이미지 편집 모드로 전달"로 바로
넘어가 파일명 변경·크롭·화질 조정을 이어갈 수 있습니다. adb가 없거나 폰이
연결되지 않은 컴퓨터에서는 안내 문구만 보이고 자동으로 비활성화됩니다.
"새로고침"을 눌러도 반응이 없을 땐 "진단" 버튼으로 adb 경로와 adb devices의
원본 결과를 확인할 수 있습니다.

adb.exe는 시스템 PATH에 없어도 흔한 설치 위치(Android Studio 기본 설치 경로,
이 프로그램과 같은 폴더의 platform-tools 등)를 **자동으로 찾습니다** — 아무 것도
안 해도 되는 경우가 많습니다. 그래도 못 찾으면 "adb 위치 지정" 버튼을 누르면
다운로드 주소와 사용법을 먼저 안내해 준 뒤 파일 선택창이 뜹니다: ① 안내된
구글 공식 페이지에서 "platform-tools"를 내려받아 아무 폴더에나 압축을 푼다 →
② adb.exe 파일 선택 → 자동으로 새로고침까지 실행되며, 이후 이 경로를 항상 씁니다.

### 🏆 대진표 작성기

체육 수업에서 그 시간에 있는 반의 학생만으로 대진표·리그 일정을 만들 때 씁니다.
학년·반·번호·이름·성별이 담긴 학급 명단 엑셀을 한 번만 올려 두면 계속 유지됩니다
(엑셀 업로드·지우기는 자주 쓰지 않는 기능이라 좌측 맨 아래에 있습니다).

| | |
|---|---|
| **참가자 선택 탭** | 명단이 학년+반 단위로 나오고(전체 펼치기/접기 토글로 한 번에 여닫을 수 있고, 기본은 접힘), 반을 체크하면 그 반 학생 전체가 자동으로 체크됩니다. 오늘 결석한 학생만 체크를 풀면 됩니다. 이름은 "이름(번호)"만 표시되고, 승패·자동등급·교사등급 열은 가운데 정렬 + 내용에 맞춰 폭이 자동으로 줄어듭니다 |
| **종목·형식·팀당 인원** | 배드민턴/탁구/농구/기타 중 종목을 고르고, **리그전/토너먼트 라디오 버튼**(리그전이 기본)과 팀당 인원(1=개인전, 2=복식, 3 이상=단체전)을 정하면 "배드민턴_1학년1,2반_리그전_20260918" 같은 이름이 자동으로 만들어집니다 |
| **실력 등급** | 참가자 표가 이름/승패/자동등급/교사등급 4개 열로 나뉩니다. 참가자를 오른쪽 클릭해 상/중/하를 직접 매길 수 있고(항상 우선 적용), 안 매긴 학생은 누적 승률로 추정한 등급(참고용)을 대신 씁니다. **상은 금색, 중은 은색**으로 그 줄이 옅게 칠해지고, **대진표 탭에서도 같은 색**이 적용돼 어느 등급끼리 겨루는지 한눈에 보입니다. "실력 고려"는 **기본이 "수준별 분리"**라 등급마다 대진표를 따로 만듭니다 |
| **회차 관리(시리즈)** | 대진표 탭 위쪽에 **시리즈**(종목+반) 콤보와 **회차**(진행률 "3/10"·"완료" 표시) 콤보가 있습니다 — "회차"는 팀 편성부터 그 팀들의 경기가 전부 끝나기까지 한 사이클을 뜻하며, 리그 표의 "N라운드"(리그 자체의 대진 회전)와는 다른 개념입니다. "생성"을 누르면 그 반·종목의 시리즈를 찾거나 새로 만들어 회차를 추가하고, 누적 엑셀과 같은 폴더에 시리즈 파일(JSON)로 즉시 저장합니다 — 수업이 한 교시에 안 끝나도, 다음에 같은 시리즈를 고르면 그 회차 그대로 이어서 기록합니다. 짝을 반복해서 이루지 않도록 팀을 짤 때도 이제 **그 시리즈의 모든 이전 회차**를 보고 판단합니다(엑셀 저장 여부와 무관) |
| **오늘 출석 조정** | 회차 진행 중 결석이 생기면 누릅니다. 팀별 체크박스(기본 전원 출석)에서 결석자를 풀면, 한 명만 남는 팀이 생길 때 그 자리에서 "다른 팀에서 빌려오기"(3인 이상 팀이 있을 때) 또는 "2인 팀에 합류"(오늘만 3인 팀)를 고를 수 있습니다. 조정은 **오늘 날짜에만** 적용되어 다음 수업일엔 기본 팀으로 자동 복귀하고, 대진표 화면에도 결석자는 취소선·임시 합류자는 "(임시)"로 바로 반영됩니다. 이미 기록한 경기는 그때의 실제 출전자 그대로 남습니다 |
| **팀 레벨 균형** | "실력 고려"의 기본값입니다. 등급(상=3점/중=2점/하=1점, 교사 등급 우선·없으면 자동 등급)을 매겨 **모든 팀의 평균이 2에 가깝도록**(1.5~2.5 안으로) 팀을 짭니다 — 실력이 고른 팀끼리 겨루게 하고 싶을 때 씁니다 |
| **여학생 표시** | 참가자 선택 탭에서 성별이 "여"인 학생은 이름·번호 뒤에 옅은 붉은 원이 표시됩니다 |
| **대진표 탭** | "생성"을 누르면 자동으로 이 탭으로 전환됩니다. 두 참가자가 채워진 칸(토너먼트)이나 경기 행(리그)을 클릭하면 **세트별 점수만 입력**해 결과를 기록할 수 있고(승패는 자동 계산, "2:1"로 요약 표시), 화살표 키로 입력 칸을 옮겨 다닐 수 있습니다. 토너먼트는 승자가 다음 라운드로 자동으로 올라갑니다. 복식·단체전의 팀원 이름은 칸 안에서 줄바꿈되어 다 보입니다 |
| **학생 추가 배정** | 결석이나 홀수 인원으로 팀을 못 채운 학생을 다른 팀에 강제로 추가합니다(그 팀은 3인 팀이 되고, 경기 결과는 팀 전원이 동일하게 받습니다) |
| **경기 결과 저장·합치기** | "경기 결과 저장"은 누적 엑셀 파일에 이어서 기록합니다(처음 한 번만 파일을 고르면 계속 이어 붙고, 같은 결과를 두 번 눌러도 중복으로 안 쌓입니다). "경기 결과 합치기"는 다른 컴퓨터의 시리즈 파일을 골라 지금 시리즈에 합칩니다 — 없는 회차·경기는 그대로 가져오고, 결과가 서로 다르면 어느 쪽을 남길지 하나씩 물어봅니다 |
| **성적 산출**(왼쪽 종목 패널) | 지금 시리즈에 쌓인 모든 회차의 경기 결과로 학생별 경기수·승·패·승률을 집계해 엑셀로 저장합니다(학기 말 개인 성적 처리용, 매번 쓰는 기능이 아니라 왼쪽 종목 카드에 따로 있습니다). 결석으로 못 뛴 경기는 안 셉니다 |

### 🧬 코돈표 계산기

DNA 또는 mRNA 서열을 입력하면 표준 유전암호표로 아미노산 서열을 바로 찾아 줍니다.
수능 생명과학의 코돈 문제를 검토할 때 씁니다.

| | |
|---|---|
| **DNA 입력 — 5단계 과정** | 입력한 서열이 주형 가닥(3'→5')인지 암호화 가닥(5'→3')인지 고르면, 나머지 가닥 찾기 → mRNA 합성(전사) → 코돈으로 3개씩 묶기 → 아미노산 번역까지 교과서 순서 그대로 한 단계씩 보여줍니다 |
| **mRNA 직접 입력** | 전사 단계 없이 바로 코돈→아미노산 표로 번역합니다 |
| **번역** | 종결코돈(UAA/UAG/UGA)에서 멈춥니다 |
| **역조회** | 아미노산을 고르면 그 아미노산을 지정하는 코돈을 전부 보여줍니다 |
| **전체 코돈표** | 64개 코돈을 표준 배열(첫 글자 U·C·A·G 순)로 참고할 수 있습니다 |

### 🧪 코돈시뮬 (CodonSim)

기출 문제를 w(주어진 주형 가닥)에서 시작해 x→y→z로 이어지는 변이를 직접 만들어 보며
푸는 화면입니다. 코돈표 계산기가 "서열 → 결과 즉답"이라면, 코돈시뮬은 "조건에 맞을 때까지
직접 시도해 보는" 과정형 도구입니다.

| | |
|---|---|
| **w → x → y → z 4단 카드** | 각 카드에서 서열을 클릭해 위치를 고르고, 삽입/삭제/치환 중 하나를 적용하면 바로 아래에 결과(DNA·mRNA·아미노산)가 나타납니다. 바뀐 자리는 노란색, 부모 단계와 달라진 아미노산은 빨간 테두리로 표시됩니다 |
| **조건 판정판** | 지금까지 만든 x/y/z가 문제의 조건(예: "x는 서로 다른 아미노산 8개")을 만족하는지 실시간으로 채점합니다 |
| **힌트 → 정답 → 자동 채우기** | 막히면 힌트 1·2단계를 순서대로 보고, 그래도 안 되면 정답을 확인한 뒤 한 번에 채워 넣어 결과를 볼 수 있습니다 |
| **&lt;보기&gt; ㄱ/ㄴ/ㄷ** | 지금 만든 x/y/z를 기준으로 O/X를 채점합니다(동의코돈 때문에 여러 정답 후보가 있을 수 있다는 점도 그대로 드러납니다) |
| **직접 입력** | 문제 콤보에서 "직접 입력"을 고르면 원하는 주형 가닥으로 자유롭게 변이를 실험할 수 있습니다(이 모드는 조건·&lt;보기&gt; 없이 탐색만 지원) |

1차 배포에는 2019학년도 수능 생명과학Ⅰ 21번 문제가 들어 있고, 문제 데이터만 추가하면
다른 기출도 쉽게 늘릴 수 있는 구조입니다.

## 🚀 실행

```bash
pip install -r requirements.txt
python FolderKitPP.py
```

윈도우에서는 `run.bat`을 더블클릭해도 됩니다(파이썬 경로가 다르면 메모장으로
열어 `PYEXE` 줄만 고치세요).

## 🔧 요구 사항

- Python 3.9 이상, PySide6 6.5 이상, Pillow, send2trash
- 선택: `xxhash`(중복 찾기 가속), `pillow-heif`(아이폰 HEIC 사진)
- **유틸리티 모드는 추가 설치가 필요 없습니다** — 표준 라이브러리만 씁니다.
