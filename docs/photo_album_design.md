# 사진첩(행사·장소·인물 자동 분류) 설계 (v48, v49)

## 1. 화면
이미지 편집 모드 왼쪽 패널 위에 **[폴더 | 사진첩]** 전환을 둔다.
- 폴더: 지금까지의 폴더 트리(다른 모드와 공유하는 위젯을 이 칸으로 옮겨 붙인다).
- 사진첩: 보관함의 행사 목록. 행사를 고르면 그 사진들이 아래 썸네일 줄에
  깔리고, 크롭·커브·저장·이동·복사·JPG 변환은 폴더에서와 똑같이 쓴다.

원본 파일은 연/월 폴더에 그대로 두고, 사진첩은 그 파일을 가리키기만 한다
(가상 앨범).

## 2. 모듈
```
main_window.py          [폴더|사진첩] 전환, 행사 사진 불러오기, 썸네일 오른쪽 클릭(정정)
photo_album_panel.py    사진첩 패널(행사 목록, 이름·합치기·다시 분류), 분석 워커
photo_album_core.py     Qt 없음 — 폴더 훑기, 촬영 시각·특징값, 행사 묶기, 정정, DB
image_io.py             EXIF 방향(특징값도 사람이 보는 방향 기준으로 뽑는다)
```

## 3. 보관함과 DB
보관함은 갤럭시폰 사진 옮기기와 **같은 폴더**(QSettings `util.phonetransfer.library_dir`).
```
<보관함>/.folderkit/phone_sync.db     전송 기록(사진 옮기기)
<보관함>/.folderkit/photo_album.db    사진첩
```
- photos(rel, size, mtime, taken, feature, event_id, manual)
- events(id, name, locked)

name이 비어 있으면 화면에서 날짜로 표시한다(문구는 저장하지 않는다).

## 4. 분석(새로 생기거나 바뀐 사진만)
1. 보관함을 훑어 DB와 맞춘다 — 없어진 사진 삭제, 새 사진 추가, 크기·시각이
   바뀐 사진(편집해 저장)은 특징값만 비운다(행사는 그대로).
2. 특징값이 없는 사진만 연다: EXIF 촬영 시각(없으면 파일 수정 시각),
   특징값 128바이트(색 분포 64칸 + 8×8 밝기 배치). JPEG는 작게 디코딩해서 빠르다.
3. 행사가 없는 사진만 묶는다(이미 분류된 사진은 건드리지 않는다).

## 5. 묶는 규칙
촬영 시각 순으로 늘어놓고, 앞쪽 최근 사진(최대 20장, 36시간 안)과 비교해
처음 맞는 행사에 붙인다. 앞에서 못 찾으면 뒤쪽 사진과도 비교한다.

| 시간 간격  | 같은 행사 조건 |
|-----------|----------------|
| ≤ 2시간    | 무조건 |
| ≤ 12시간   | 배경 거리 ≤ 0.30 |
| ≤ 36시간   | 배경 거리 ≤ 0.18 |
| > 36시간   | 다른 행사 |

값은 `photo_album_core.py` 맨 위 상수에 모여 있다. 실제 사진으로 써 보며
조정한다.

## 6. 정정
| 동작 | 어디서 |
|------|--------|
| 다른 행사로 옮기기(앞뒤 행사 바로 / 목록에서 고르기) | 썸네일 오른쪽 클릭 (Ctrl·Shift로 여러 장) |
| 선택한 사진으로 새 행사 | 썸네일 오른쪽 클릭 |
| 이름 바꾸기 / 날짜 이름으로 되돌리기 | 행사 더블클릭·F2·오른쪽 클릭 |
| 여러 행사 합치기 | 행사 여러 개 선택 후 오른쪽 클릭 |
| 다시 분류 | 패널 아래 버튼 |

사용자가 손댄 행사(옮겨 넣기·빼기, 분리, 합치기, 이름 바꾸기)는 `locked=1`이
되고 "다시 분류"에서 통째로 지켜진다.

## 7. [v49] 장소
- EXIF GPS(위·경도) → `geo_lookup.place_key()` → 내부 키.
  - 대한민국: 통계청 2018 시·군·구 경계 안에 드는지 직접 판정(점-다각형).
    경계 바로 밖(해변 등)은 약 5km 안의 가장 가까운 시·군·구. `KR-<코드>`.
  - 해외: GeoNames 인구 1만5천 명 이상 도시 중 가장 가까운 곳, 단 15km 안에
    더 큰 도시가 있으면 그쪽(도쿄의 구 → Tokyo). `W-<나라>-<GeoNames id>`.
  - 인터넷 없이 동작한다. 자료: `assets/geo/`(약 1MB, 출처는 그 폴더 README).
- 화면: 장소 → 시·도/나라 → 시·군·구/도시, 맨 아래 "위치 정보 없음".
  이름은 표시할 때 번역 표·자료에서 만든다(시·도와 자주 가는 나라는 3개 언어).
- 정정 없음 — GPS가 정하는 사실이다.

## 8. [v49] 인물 (선택 설치)
- 필요: `opencv-python` + `models/`의 YuNet·SFace(해시 검사). 없으면 인물 칸에
  설치 안내만 보인다.
- 사진마다 긴 변 1280px로 줄여 얼굴을 찾고(작은 얼굴은 뺌), 정렬한 얼굴에서
  특징값 128개를 뽑아 길이 1로 맞춘다. 작은 얼굴 그림(72px JPEG)도 저장.
- 묶기: 새 얼굴만, 기존 인물의 평균 얼굴과 코사인 유사도 ≥ 0.40이면 그 인물,
  아니면 새 인물(OpenCV 권장 기준 0.363보다 조금 엄격).
- 사진 2장 이하 인물은 "자주 안 나온 얼굴"로 모은다(이름 붙이면 목록으로).
- 정정: 썸네일 오른쪽 클릭 — 다른 인물로 옮기기, 새 인물 만들기, "이 사람이
  아님"(다시 묶어도 다시 들어가지 않음). 인물 목록 — 이름, 합치기.
- 손댄 인물은 locked=1, "다시 분류"에서 그대로.
- DB: `persons(id, name, locked)`, `faces(id, rel, x, y, w, h, score, emb, thumb,
  person_id, excluded, manual)`. v48 DB는 열 때 칸을 덧붙인다(기존 기록 유지).

## 9. 분석 단계
보관함 훑기 → 촬영 시각·배경(새 사진) → 행사 묶기 → 장소(GPS, EXIF만 읽음) →
얼굴(엔진이 있을 때) → 인물 묶기. 단계마다 멈춤 가능, 다음에 이어서.
