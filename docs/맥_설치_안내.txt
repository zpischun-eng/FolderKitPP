FolderKit++ 맥(Mac) 설치 안내
================================

1. 설치
   - 내려받은 .dmg 파일을 두 번 클릭해 엽니다.
   - 열린 창에서 "FolderKit++" 아이콘을 옆의 "Applications"(응용 프로그램) 폴더로 끌어다 놓습니다.
   - 끝입니다. 이제 응용 프로그램 폴더(또는 Launchpad)에서 FolderKit++를 켤 수 있습니다.

   ※ 내려받은 파일 이름에 "apple-silicon"이 붙은 것은 M1·M2·M3·M4 맥용,
     "intel"이 붙은 것은 예전 인텔 맥용입니다.
     내 맥이 어느 쪽인지는 화면 왼쪽 위 사과 메뉴 → "이 Mac에 관하여"에서
     "칩: Apple M…"이면 애플 실리콘, "프로세서: Intel…"이면 인텔입니다.

2. 처음 켤 때 경고가 뜨면 (한 번만 하면 됩니다)
   이 프로그램은 애플 앱스토어를 거치지 않은 개인 제작 프로그램이라, 처음 켤 때
   "Apple은 'FolderKit++'에 악성 코드가 없음을 확인할 수 없습니다" 같은 경고가 뜹니다.

   [macOS 15 세쿼이아 이후]
   ① 경고 창에서 "완료"를 누릅니다.
   ② 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 갑니다.
   ③ 아래쪽 "보안" 칸에 "FolderKit++이(가) 차단되었습니다" 옆의 "그래도 열기"를 누릅니다.
   ④ 맥 비밀번호(또는 Touch ID)를 넣으면 켜집니다. 다음부터는 그냥 켜집니다.

   [macOS 14 소노마 이전]
   응용 프로그램 폴더에서 FolderKit++를 마우스 오른쪽 클릭(또는 control + 클릭) → "열기"
   → 다시 "열기"를 누릅니다. 다음부터는 그냥 켜집니다.

   [그래도 "손상되었기 때문에 열 수 없습니다"라고 나오면]
   응용 프로그램 폴더 → 유틸리티 → "터미널"을 열고 아래 한 줄을 붙여 넣은 뒤 return 키:
       xattr -dr com.apple.quarantine /Applications/FolderKitPP.app
   그다음 다시 켜 보세요.

3. 폴더 접근 허락
   데스크탑·문서·다운로드·USB 폴더를 처음 열 때 맥이 "접근을 허용하겠습니까?"라고 묻습니다.
   "허용"을 눌러 주세요(폴더를 정리·동기화하려면 필요합니다).

4. 맥판에서 달라지는 점
   - "탐색기에서 열기"는 "Finder에서 보기"로 동작합니다.
   - 단축키의 Ctrl은 맥에서는 ⌘(command) 키입니다. (Alt는 option 키)
   - 미니앱은 계산기·함수 그래프·스도쿠·행운의 번호·응원의 메시지·타이머/시계만 들어 있습니다.
     (학교 업무용 도구와 갤럭시폰 사진 옮기기는 윈도판에만 있습니다.)

5. 문제가 있으면
   어떤 화면에서 무엇을 눌렀을 때 어떻게 되었는지, 가능하면 화면 캡처(⌘+shift+4)와 함께
   알려 주세요.
